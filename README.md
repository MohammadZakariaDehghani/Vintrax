# Atlas

Project Atlas is a planned vehicle commerce platform for Canada: a trusted, easy-to-use marketplace connecting buyers, dealerships, and private sellers, with direct buyer-to-seller messaging and a future auction application built on shared platform foundations.

The project is currently in the discovery and planning phase — see the documents below for the full picture.
